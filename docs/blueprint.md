# **App Name**: PrintFlow Manage

## Core Features:

- Secure User Authentication & Authorization: Robust login system for Admin and Staff, ensuring role-based access to dashboards and functionalities.
- Order Creation & Assignment: Admin dashboard feature allowing creation of new work orders with customer details, work type selection, and staff assignment.
- Staff Task Management: Staff-specific interface to view assigned orders, upload design proofs or completed work images, and update order statuses.
- Admin Order Dashboard & Staff Management: Comprehensive Admin dashboard to view all orders, filter by status, manage staff accounts, and oversee project workflows.
- Customer Order Tracking Portal: A public-facing page where customers can check order status and view uploaded preview images using a unique Order ID and phone number.
- Integrated Cloud File Storage & Preview: System for securely uploading, storing, and providing previews of various design files (e.g., PDFs, images) for orders.
- AI Design Brief Tool: An AI tool to assist Admins or Staff in generating detailed and structured design brief suggestions based on project type and keywords.

## Style Guidelines:

- Primary color: A sophisticated, deep blue (#2262BD), chosen to convey professionalism and reliability, providing excellent contrast on lighter backgrounds.
- Background color: A very light, desaturated cool gray-blue (#EBF1F5), promoting a clean and modern aesthetic that enhances readability without distraction.
- Accent color: A bright, clear cyan-blue (#18CEDD), used for interactive elements like buttons and highlights to draw attention and add a touch of modern dynamism.
- Headline and body font: 'Inter' (sans-serif), chosen for its modern, neutral, and highly legible characteristics, suitable for data-rich dashboards and clear information display.
- Utilize a consistent set of minimalist, outlined system icons to maintain a clean, professional, and intuitive user interface.
- Employ a responsive grid-based layout with adaptive cards and clearly delineated sections to ensure optimal usability across all devices.
- Implement subtle and functional animations for transitions, form feedback, and loading states to enhance the perceived responsiveness and user experience.
